The deployment profile

The platform and operating target for a system.

A Deployment Profile describes the intended application and operating conditions for a specified vehicle and hardware configuration.

Software candidates can share a profile, provided their requirements fit.

🚗 Vehicle platform
Vehicle, sensors, compute, actuation, and interfaces.
🌍 Operating conditions
Roads, speed, weather, lighting, and other ODD boundaries.
🎯 Use case
Driving functions and driver or operator responsibilities.

The profile states the target. The integrated design defines its ODD and records what evaluation supports.

The reference software stack

A software configuration Autoware publishes and maintains as a recommended baseline.

Rule-based Planning

Localization and perception, rule-based planning, control, and supporting modules.

Diffusion Planning

A specified diffusion planner, required inputs, trajectory checks, and control.

Meteor-based

A specified Meteor model, runtime, adapters, and supporting Autoware modules.

Vision Pilot

AutoSteer, AutoSpeed, AutoDrive, and explicitly selected supporting modules.

Fusion Pilot

AutoE2E, input processing, runtime, output adapters, and supporting modules.

A name resolves to a configuration.Modules, model versions, parameters, interfaces, and platform requirements.

These are candidate baselines. Their complete manifests and supported deployment profiles remain to be specified.

The complete system blueprint

A documented, versioned reference design makes the system reproducible and assessable.

Purpose
Driving functions, use case, automation target, and human responsibilities.
Operating domain
Conditions, boundaries, assumptions, and exclusions.
Platform
Vehicle, sensors, compute, actuation, and interfaces.
Software
Selected modules, models, versions, parameters, and dependencies.
Integration
Calibration, timing, maps, resources, and deployment instructions.
Evaluation
Criteria, tested configurations, results, and known limitations.

A reference design can begin as a draft. Its status must distinguish intended capability from demonstrated results.
